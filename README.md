# teen-mental-health-analysis
Exploratory Data Analysis on Social Media Impact on Teen Mental Health using Python, Pandas, Matplotlib &amp; Seaborn
# Social Media Impact on Teen Mental Health
### By Maroof Ali — CS Student | Aspiring AI Engineer

## Overview
Exploratory Data Analysis (EDA) project on a dataset of 1200 teenagers
to understand how social media usage affects mental health.

## Tools & Libraries
- Python
- Pandas & NumPy (Data Cleaning & Analysis)
- Matplotlib & Seaborn (Data Visualization)

## Dataset
- 1200 rows, 13 features
- Features: age, gender, platform usage, sleep hours,
  stress level, anxiety level, addiction level, depression label

## Key Findings
- Only 2.6% teens show depression signs
- Depressed teens use social media more hours per day
- More social media hours = less sleep (negative correlation)
- TikTok users show higher stress than Instagram users
- Stress and anxiety are positively correlated
